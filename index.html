O que o Parrot PHP oferece

⚡

Performance Acima de Tudo

Equipado com FastRoute para roteamento ultrarrápido e PHP-DI para injeção de dependências eficiente. Padrão PSR-7/PSR-15 incorporado.

🛡️

Segurança Nível Bancário

Autenticação via JWT em cookie HttpOnly e SameSite=Strict. Rate limiting nativo, CORS, proteção CSRF e senhas criptografadas em Argon2id com blacklist de tokens revogados.

🗄️

Eloquent ORM

Use o renomado Illuminate/Database. Manipule o banco de dados com a mesma facilidade do Laravel, sem sacrificar a velocidade de um micro-framework.

🧪

Testado Batalhando

O pacote inclui PHPUnit 11 configurado com testes integrados rodando direto contra bancos de dados MySQL/MariaDB, garantindo resiliência em ambiente real.

Beleza e Simplicidade em Ação

config/routes.php
use App\Controllers\UserController;
use App\Controllers\AuthController;
use App\Middlewares\JwtAuthMiddleware;

return [
    // Rotas de Autenticação com rate limit personalizado
    'POST /api/auth/login' => [AuthController::class, 'login', 'rate_limit_login'],
    
    // Rotas limpas e fáceis de entender, com middleware de Auth
    'GET /api/usuarios'      => [UserController::class, 'index', JwtAuthMiddleware::class],
    'GET /api/usuarios/{id}' => [UserController::class, 'show', JwtAuthMiddleware::class],
    'POST /api/usuarios'     => [UserController::class, 'store', JwtAuthMiddleware::class],
];
